# Лабораторная работа №2 — камера и освещение

Вариант 1 — куб. C++20, Vulkan, GLFW, ImGUI.

Реализованы камера с изменяемыми положением, поворотом и углом обзора, процедурные нормали граней куба и модель Блинн-Фонга во фрагментном шейдере.

Все дополнительные задания:

1. Отдельные наборы дескрипторов сцены (`set = 0`) и модели (`set = 1`).
2. Добавление и удаление точечных источников, их параметры и затухание `1 / r²`.
3. Добавление и удаление прожекторов, затухание `1 / r²`, внутренний и внешний углы, мягкие края.
4. Цветные маркеры источников и белые конусы прожекторов с возможностью скрытия. Маркеры и конусы не освещаются.

Точечные источники и прожекторы хранятся в двух storage-буферах с массивами `lights[]` без фиксированного размера в шейдере. Буферы растут при добавлении источников; физический предел задаётся устройством Vulkan.

## Запуск

На macOS нужны CMake, `glslc`, загрузчик Vulkan и MoltenVK. Для валидации нужен пакет Vulkan Validation Layers.

```bash
bash run-macos.sh
```

Для Windows или Linux установите Vulkan SDK и CMake:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build build --config Debug
```

На Linux запустите `./build/vulkan-lighting-app`, на Windows — `build/Debug/vulkan-lighting-app.exe` для Visual Studio или `build/vulkan-lighting-app.exe` для одноконфигурационной сборки. При первом конфигурировании CMake скачивает зависимости. Рабочая директория — папка `lab2`.

## Управление

- **Camera** — положение, yaw, pitch, угол обзора.
- **Model and material** — перенос, поворот, масштаб, альбедо, цвет блика и коэффициент блеска.
- **Ambient and directional** — рассеянный свет и направленный источник.
- **Point lights / Spot lights** — выбор источника, добавление, удаление и параметры.
- **Show light sources** — маркеры и конусы; **Show floor** — пол.
- **Reset scene** — начальное состояние. **Save image** сохраняет `lighting.ppm`.

Если все компоненты направления источника равны нулю, используется направление вниз. Внутренний угол прожектора не превышает внешний; при равных углах граница резкая. Масштаб модели ограничен положительными значениями для корректной матрицы нормалей.

## Проверки

```bash
ctest --test-dir build --output-on-failure
cmake -S . -B build -DRENDER_TEST=ON
cmake --build build --config Debug
```

`render_test` запускает настоящий Vulkan-рендерер: проверяет элементы интерфейса, пустые массивы света, рост storage-буферов, обратные квадраты расстояния, мягкие края, постоянный цвет маркеров и изменение размеров окна. Для macOS задайте переменные драйвера и слоёв так же, как в `run-macos.sh`, затем запустите `./build/render_test` из `lab2`.

Проверено на macOS с MoltenVK и валидацией Vulkan. При сборке возможны предупреждения из внешнего заголовка Vulkan Memory Allocator.
